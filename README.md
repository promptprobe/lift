# lift

Plan an A/B test before you peek. Paste a baseline conversion, a minimum detectable effect, and daily traffic — get sample size, days-to-significance, and a peeking-risk warning.

https://promptprobe.github.io/lift/

Math runs in the browser (two-sample binomial, unpooled, Bonferroni for 3–6 variants). No accounts, no API, no data leaves the machine.
